## 本轮开发内容

1. 在现有EP上增加默认关闭的P2能力，实现绑定源function的Host访问服务，使用`pci_dma_rw()`和真实QEMU IOMMU；限制Host RAM访问，拒绝MMIO/P2P误路由。

6. 增加统一顺序验收入口、逐组日志及manifest，并将完整P1回归列为本轮门禁。运行文件继续ignore。

### 开发期间实际失败及修复

1. MCU 在软件 ready 前轮询 IPC 时，旧的非 ready 处理拒绝整个代理槽，导致后端启动失败。改为允许寄存器代理，外部数据搬运继续要求 ready。
2. ISR 汇编最初位于 `.bss`，已显式放回 `.text`。IRQ 源清除与模型采样存在延迟，ISR 忽略空源并清本地 pending，不让空 ISR 覆盖完成状态。
3. 超时保护使用 `rdcycle` 时，在当前 MCU 配置触发非法指令；Linux 连续任务失败，诊断 `mcause=2`。改为有界循环，超时先停通道再返回错误；不是增加超时时间掩盖问题。
4. inbound 控制器目标落在旧 DDR0 范围，修正为控制器/IPC 优先于 RAM；测试使用与旧寄存器不同的值验证，避免同值假阳性。
5. 生成证据的源码/二进制 manifest 必须与最终工作区核对；修正后的构建在旧验收进程结束后执行，不在运行中替换二进制。

### 完整 P2 关闭边界

`p2_extended_functional_pass=true` 表示当前功能配置通过，`p2_full_exit` 继续为 false。未关闭事项具体为：芯片物理 MCU IRQ 编号；硬件 NPU 通道错误 ABI；当前单 PF Memory 子集以外的 iATU/HDMA 高级特性；生产工具链文件/任务解析与真实 Tensor 数值闭环；全部引擎断连/FLR/并发 reset 竞争矩阵。已完成的功能无需继续标为“尚未实现”，未覆盖项也不能由本次测试外推。
