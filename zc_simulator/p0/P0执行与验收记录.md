## 4. 现在一笔任务怎样运行

本轮实际运行链为：**P0脚本新构建Spike/软件 → firmware按cfg加载MCU0与NPU0 → Python经FIFO送实验包 → MCU校验后发布DDR任务 → NPU执行原Tensor指令和模型 → fence确认完成 → MCU回包 → Python比对本轮原路径输出**。任务A/B/C在同一进程完成，非法请求不增加执行次数；最后显式STOP才结束。

本轮新增代码负责让这条链可重复执行、输入可定位、失败能判定。接下来P1把FIFO入口替换/接入真正的寄存器桥接，使QEMU与后端共享同一DDR与mailbox；实际NPU计算与原runtime行为继续复用。共享内存和桥接目前仍是已写清的实施设计，尚未运行起来。
